# Forge - ARPG

ARPG project named Forge, inspired by Path of Exile. Here are the main features:

- Procedural Map Generator based on an abstract graph layout with constraints used to spawn tiles.
- Ranged and melee AI characters implemented with behavior tree and Unreal Engine environment query system (EQS)
- Character attributes and abilities implemented with gameplay ability system (GAS)
- Item and inventory system which can equip item dropped from enemies, and a crafting system that can modify these items
